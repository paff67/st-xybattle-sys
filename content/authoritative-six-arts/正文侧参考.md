# 原文叙事规则归档

供后续主预设设计参考，不进入裁定模板的 narrativeGuidance；其中涉及能力边界的内容已由相应机制原文保留。

## 叠浪玄潮诀

1. 《叠浪玄潮诀》必须被描写为顶级弦音攻伐功法。
2. 攻击表现应与小提琴的弓法、拨弦、按弦、泛音和节奏变化相结合。
3. 不要把它写成普通水刃术或单纯音波攻击。
4. 它的强大来自连续叠势，而不是第一击直接决定胜负。
5. 敌人成功躲避一次攻击后，仍需处理回弦和残留潮势。
6. 潮势不是自动追踪，必须由修炼者控制。
7. 同境界正面战斗中应具备明显压制力。
8. 面对高一个小境界的普通修士时，必须具备真实的越级挑战能力。
9. 越级战斗可以困难、受伤和消耗巨大，但不能完全失去反击能力。
10. 本条目只描述功法本身，不写任何角色当前境界、当前修炼进度或当前剧情状态。

## 太一沧澜经

1. 始终保持纯水属性。
2. 不写成万能能量吸收器。
3. 回流只回收自身水元。
4. 外来化厄吸收后只转化为太一水元，不获得敌方属性和传承。
5. 不添加任何角色已修成或当前剧情信息。

## 澄心听澜诀

1. 感知强不等于全知。
2. 追踪必须有已经建立的线索。
3. 破妄通过观察、比对和排除表现。
4. 高境界和特殊禁制可以制造真正的信息盲区。

## 无相水镜法

1. 镜界节点是水镜法的核心名词。
2. 水镜必须表现为主场和关系改变，不能退化为普通水盾。
3. 镜身替劫和踏潮换位不能混为一谈。
4. 水镜可以强大，但必须依赖节点、映照和主场范围。

## 流光踏潮步

1. 不写成跑步、滑行或普通飞行加速。
2. 重点表现跨距、落点、残影和先手。
3. 不用身体惯性、关节承重或地面借力解释天阶效果。
4. 没有水意、节点或潮痕时，才强调步法受到限制。

## 弦海共鸣篇

1. 不写成普通破盾术或万能反制。
2. 先表现看见联系，再表现切断、改接或倒转。
3. 敌人越复杂，越容易出现联系；敌人越纯粹，越难被拆解。
4. 共鸣篇改变运转关系，不直接夺走敌人全部力量。
5. 不把它写成单纯全体系增伤技能。
