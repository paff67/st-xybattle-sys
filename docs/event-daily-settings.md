# 非战斗裁定自主配置

入口：独立机枢 → 非战斗裁定 API / 非战斗裁定提示词。修改后点击“保存机枢设定”，后续事务使用新配置。

## API

- 默认沿用战斗裁定 AI 的连接、模型、API Key、温度、最大输出和单次请求超时。
- 关闭沿用后，可以使用独立 OpenAI-Compatible 接口。初次切换会复制当前战斗配置作为起点；之后切换沿用不会覆盖独立配置。
- 此连接用于自动分流、资料提取、非战斗裁定及正文完成后的战斗识别。人物档案生成与战斗开战后的裁定继续使用各自的 API 配置。
- 独立非战斗接口可以在战斗裁定接口尚未配置时启用。
- 整次事务总时限独立设置，覆盖分流、资料提取与多行动裁定。单次超时和总时限任一到达即停止；没有自动失败重试。
- 旧设置没有总时限字段时，以原裁定单次超时的四倍初始化，最低 120 秒；之后保存为明确配置值。

## 提示词

可以编辑通用提示词及修炼突破、炼丹、炼器、探查、疗伤、破阵、追逃、日常事务八个模块提示词。每次最终裁定仅拼接通用提示词和当前模块提示词。分流与资料提取仍使用各自的固定协议。

每项都可恢复默认；留空并保存也会恢复该项默认。恢复操作只修改当前表单，点击保存后生效。自定义提示词不会取消程序的结构、证据引用、版本与资源变更校验，修改时应保留既有 JSON 返回接口。

## 持久化与验证

设置使用现有浏览器本地全局设置存储，刷新和切换聊天后可复用。`dailyAdjudicator` 保存独立接口参数，`dailyTotalTimeoutMs` 保存事务总时限，`dailyPrompts.common / modules` 保存提示词。API Key 使用单独的凭据存储，日志与战报导出会脱敏；清空密钥并保存即可移除。

启动恢复与界面保存共用 `dailyRuntimeSettings()`，确保二者使用相同配置。测试覆盖独立/沿用切换、刷新恢复、八模块提示词保存、默认恢复、凭据脱敏、实际 HTTP 请求参数和 Vue 界面保存到运行时的链路。HTTP 测试使用本地模拟响应，未调用真实模型或验证线上 ST。
